# SmartLand website

A static, right-to-left Arabic website built with HTML, CSS, and vanilla JavaScript. It has no package install or build step.


## Project layout

- `index.html` — page content, service gallery, project list, and video dialogs.
- `css/style.css` — layout, responsive styles, phone animation, and gallery transitions.
- `js/main.js` — animation loop support, swipe/drag gallery controls, and project video dialogs.
- `assets/images/` — logos and service gallery images.
- `assets/video/` — project demonstration videos.
- `assets/fonts/` — locally hosted typefaces.

The gallery expects five images under `assets/images/services/`. Project video filenames and gallery paths are referenced directly in `index.html`.
